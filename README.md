# Telegram Support Bot with LLM Integration

Прогрессивный сервис поддержки клиентов через Telegram-бота. Проект реализован на современном асинхронном стеке и использует интеграцию с LLM (Большими Языковыми Моделями) для автоматического ответа на основе базы знаний (FAQ).

В случае, если нейросеть не находит ответ в базе данных, обращение автоматически переводится на живого оператора.

---

## Архитектура и Data Flow

Пользователь ➔ Telegram (aiogram) ➔ FastAPI ➔ Redis / Celery ➔ PostgreSQL + База знаний ➔ LLM ➔ Ответ пользователю

---

## Технологический стек

| Технология | Назначение в проекте |
| :--- | :--- |
| **FastAPI** | REST API для панели администратора и интеграции внутренних сервисов. |
| **aiogram** | Асинхронный фреймворк для взаимодействия с Telegram API. |
| **PostgreSQL** | Реляционная СУБД для хранения пользователей, диалогов, FAQ и тикетов. |
| **SQLAlchemy** | Асинхронная ORM для удобной и безопасной работы с базой данных. |
| **Alembic** | Инструмент для версионирования и автоматической накатки миграций БД. |
| **Redis** | Кэширование данных и брокер сообщений (Message Broker) для Celery. |
| **Celery** | Фоновое выполнение ресурсоемких задач (генерация ответов через LLM API). |
| **LLM API** | Интеллектуальная обработка запросов на основе предоставленного FAQ-контекста. |
| **Docker** | Контейнеризация всех компонентов приложения для быстрого развертывания. |
